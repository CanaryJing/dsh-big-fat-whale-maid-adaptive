# v2.3.0 — 系统提示词要求以中文进行思考

## 更新

- **中文思考写进 persona 前缀**：新增一条显式规则（排在环境、shell、目录等规则之前）——
  - 推理、权衡、计划、验证和自我纠错一律用简体中文书写，不得悄悄换成其他语言；
  - 代码、命令、文件路径、标识符、引用的日志与文档正文保持原文语言，不做翻译；
  - 可见回复仍跟随用户语言（用户说中文即用中文）。
- 这条规则属于**系统提示词**，不依赖记忆条目、会话习惯或用户当场提醒；新会话第一轮即生效。
- `persona.complete:false` 保持不变：中文思考规则与环境段 `[ENV]`、模型 ID 段 `[MODEL]`、任务模式叠加句共存，不会互相顶掉。
- **旧格式同步**：仅备查的 `agent.cordis.yml` 人设补上同一条，历史文件不再与实际发行版自相矛盾（该文件仍不参与装载）。
- 预设展示名描述、`package.json` 版本与说明、README / AIreadme 的安装验证清单同步更新。

除人设首条规则外，**行为与本机绑定逻辑与 v2.2.0 完全一致**：环境简报、实时模型路由 ID、PowerShell 7 优先验证绑定、安全工作目录、全量工具开放均未改动。

## 安装 / 升级

下载本发行版 `.tgz` 并校验 `SHA256SUMS.txt`，或使用 tag 对应源码目录：

```bash
dsh plugin --profile web add "file:/absolute/path/to/dsh-preset-big-fat-whale-maid-adaptive-2.3.0.tgz"
```

**Tauri 注意：不要以 `file:…tgz` 安装。** 使用源码目录或解压到持久目录，再执行 `dsh plugin --profile tauri add "file:/absolute/path/to/preset-directory"`，并保留目录。

Electron `desktop` 请使用桌面版自带的官方 CLI。安装后**重启对应宿主**才保证加载新代码；运行中的旧实例不会热更新人设。

## 边界

- 中文思考规则是提示词约定，不是不可绕过的强制门禁；实际语言遵循取决于模型与宿主能力。
- 规则采用英文书写以保持与前后系统提示词风格一致，关键约束（简体中文、代码保持原文）已写死在句内。
- 其余边界与 v2.2.0 相同：shell 路由只是建议，真实权限由宿主与 DSH 底座决定。
